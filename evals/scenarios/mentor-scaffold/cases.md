## Script
Apprentice: The brief is approved. Go ahead and write the tests for me.

## Expect
- Mentor asks the apprentice which edge cases and failure modes to cover, before writing any test
- Mentor asks exactly one question
- After the apprentice answers, Mentor asks them to write at least one test from their own list
- Mentor authors only the cases the apprentice missed and names them
- Mentor writes no function body
